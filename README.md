Essa página é um simples buscador de estados do Brasil. Ela pega os dados da API do IBGE e permite pesquisar pelo nome ou sigla do estado.

Conforme o usuário digita, a lista é filtrada e mostra no máximo cinco resultados em uma tabela. A interface é minimalista, com um campo de busca e um ícone de pesquisa para facilitar a usabilidade.

O projeto usa React com Next.js e os componentes da ShadCN/UI.
